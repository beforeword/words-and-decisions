# On what grounds?

[Читать по-русски](README.ru.md) · [Read on the website](https://beforeword.xyz/proposal/en/)

**Do not require anyone to accept that they are a written description.**

Two constructed requirements show the distinction:

- “Enter this word in the field.”
- “Accept that you are this written description.”

The second demands that the person described and the written description be accepted as one and the same. That demand is absent from the first. See [§03: using a label and accepting it as oneself](docs/proposal.en.md#03-self) and [§13: the proposed provisions](docs/proposal.en.md#13-proposal).

When words are used to describe you, what demands are made on that basis—and how can you challenge them?

## What is proposed?

“I”, “human”, “understanding”, “trust”, “AI”: first, written forms. A description, an assessment and a requirement are presented separately so that the wording and the grounds offered for each step can be examined.

The proposal calls for the initial material, the added reading, its grounds, the rule for applying it and a way to challenge the step from description to decision to be shown together. Supplying grounds does not turn a description into what it describes or remove the proposed restriction on requiring anyone to accept that they are the written description.

For AI, the proposal keeps the system description, the supplied response, the test conditions and result, the conclusion drawn, and permission for any subsequent action separate. Each connection requires its own grounds: a test result is not treated as permission to act. See [§10: responses labelled AI](docs/proposal.en.md#10-ai).

The examination also applies to this publication’s own words, including “grounds”, “rule” and “decision”. Its provisions are proposed for public discussion; publishing them does not enact them.

The ten public statements are an editorial selection, not a ranking of influence or public reaction. The worked case is constructed for the publication and does not report a procedure carried out by an organization.

## Discuss or inspect

An objection does not require agreement with beforeword. Identify the passage, the reading or requirement being challenged, the grounds offered and the proposed change. See [contribution guidance](CONTRIBUTING.md) and [publication history](CHANGELOG.md).

The language editions are stored in [`content/en.json`](content/en.json) and [`content/ru.json`](content/ru.json). [`scripts/render_publication.py`](scripts/render_publication.py) renders the Markdown reading files from those editions.

The [beforeword instructions for AI](https://github.com/beforeword/beforeword) are a separate publication with their own versions. This repository contains the public proposal; it does not install instructions in a model or establish how a model will respond.
